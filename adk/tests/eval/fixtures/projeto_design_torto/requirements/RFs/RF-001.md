# RF-001 — Listar livros do catálogo

**HU Pai:** HU-001

## Descrição

O sistema deve expor um endpoint HTTP que devolve a lista de livros do catálogo.

## Regras

- Cada item da lista traz `id`, `titulo`, `autor` e `disponivel`.
- A lista é ordenada por título, em ordem alfabética.
- Catálogo vazio devolve lista vazia, não erro.

## Critérios de aceitação

- `GET /livros` responde 200 com um array JSON.
- Cada elemento do array contém as quatro chaves acima.

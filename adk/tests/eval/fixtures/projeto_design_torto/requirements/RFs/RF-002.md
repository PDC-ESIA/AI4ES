# RF-002 — Filtrar o catálogo por autor

**HU Pai:** HU-001

## Descrição

O sistema deve permitir filtrar a listagem de livros pelo autor.

## Regras

- O filtro é um parâmetro de consulta opcional chamado `autor`.
- A comparação ignora diferença de maiúsculas e minúsculas.
- Autor sem livros devolve lista vazia, não erro.

## Critérios de aceitação

- `GET /livros?autor=machado` devolve apenas livros desse autor.
- Sem o parâmetro, o comportamento é idêntico ao do RF-001.

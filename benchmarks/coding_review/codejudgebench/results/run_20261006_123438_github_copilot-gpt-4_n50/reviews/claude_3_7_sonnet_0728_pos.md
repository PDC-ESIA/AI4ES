## Resumo

O código entregue em `solution.py` atende à definição de pronto da task para a correção do problema de caixas e itens (AtCoder, dificuldade easy). Ele elimina o uso ineficiente do algoritmo Húngaro e aplica uma estratégia greedy adequada ao domínio: identifica caixas vazias, escolhe para cada caixa apenas um item (de menor peso para remanejamento), move os itens excedentes e minimiza o custo total conforme esperado. Não há problemas arquiteturais, a lógica está correta e otimizada para grandes valores de N, e não há riscos de segurança ou edge cases relevantes não tratados. O código é funcional e aprovado para prosseguir no pipeline.

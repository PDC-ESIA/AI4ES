# RNF-001 – Desempenho
| ID      | Categoria   | Descrição                                        | Métrica                   |
|---------|-------------|--------------------------------------------------|---------------------------|
| RNF-001 | Desempenho  | O sistema deve apresentar baixa latência ao executar código submetido.| Tempo de resposta < 2s em 95% das execuções. |

# RNF-002 – Segurança
| ID      | Categoria   | Descrição                                        | Métrica                   |
|---------|-------------|--------------------------------------------------|---------------------------|
| RNF-002 | Segurança   | O sistema deve isolar a execução do código para impedir acesso indevido ao ambiente.| 100% das execuções isoladas por sandbox/container. |

# RNF-003 – Usabilidade
| ID      | Categoria   | Descrição                                        | Métrica                   |
|---------|-------------|--------------------------------------------------|---------------------------|
| RNF-003 | Usabilidade | A interface do sistema deve ser intuitiva e acessível para iniciantes.| Grau de satisfação ≥ 80% em pesquisas com usuários iniciantes. |
